# Finding the distance between the two points

## Description of the program
This program helps you find the distance within two points by making you input the value of each point. The program then uses your input and applies it to the distance formula (distance = math.sqrt(pow(x2 - x1, 2) + pow(y2 - y1, 2)). The program then prints the answer.

## How to Run the Program
1. Open the program.
2. Run the program.
3. Enter the required values asked by the program.
4. The program will then display the distance between the two points.

## Input Needed For the Program
- The program will ask you to input the value of x1.
- The program will ask you to input the value of y1.
- The program will ask you to input the value of x2.
- The program will ask you to input the value of y2.

## Example of the outputs given
First, you enter the values of:
- x1 = 2
- y1 = 3
- x2 = 7
- y2 = 8
If done correctly, the program should say, "The distance between the two points is:  7.0710678118654755"
